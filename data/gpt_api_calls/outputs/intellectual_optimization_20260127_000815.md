## 4) Sleep engineering (mechanisms + protocols)

Sleep is not “rest.” It is **memory consolidation + metabolic clearance + synaptic renormalization**. If you’re doing compression-driven work, sleep is part of the compression pipeline.

### 4.1 What different sleep stages do (useful mapping)
- **NREM (especially slow-wave sleep, SWS)**  
  - Supports declarative memory consolidation (hippocampus → cortex replay)  
  - Synaptic downscaling (noise reduction; improves signal-to-noise)  
  - Physical restoration, glymphatic clearance (metabolic waste)
- **REM**  
  - Associative recombination, emotional processing  
  - Creativity/insight is correlated with REM-rich late sleep  
- **Sleep spindles (N2)**  
  - Strongly linked to learning consolidation and intellectual performance markers

If you cut sleep short, you disproportionately cut REM (late night), harming insight/recombination.

### 4.2 Circadian is a performance multiplier, not lifestyle advice
Your brain’s alertness, reaction time, and executive function are modulated by:
- **SCN circadian clock** (light timing)
- **Adenosine** (homeostatic sleep pressure)
- **Cortisol rhythm** (morning rise primes wake)
- **Body temperature rhythm** (drops at night)

**The goal:** stable circadian phase + high amplitude rhythm.

### 4.3 Concrete protocol (high-leverage, minimal mysticism)
**Anchor: fixed wake time** (±30 min). Everything else follows.

**Morning (first 60 minutes after wake)**
- Bright outdoor light 5–15 min (longer if overcast). This is the strongest circadian anchor.
- No sunglasses if safe; don’t stare at sun—just ambient daylight.

**Caffeine**
- Delay caffeine ~60–90 minutes after waking to avoid stacking with cortisol peak (often improves afternoon crash).
- Set a hard cutoff: ~8–10 hours before bedtime.

**Evening**
- 2–3 hours before bed: dim house lights, reduce overhead bright/blue-heavy light.
- Keep bedroom cool. Temperature drop facilitates sleep onset.
- If you must use screens: strong blue reduction + low brightness + distance.

**Naps (optional but powerful)**
- 10–20 min “power nap” early afternoon for alertness
- Or 90 min full-cycle nap for consolidation (but can affect night sleep)

### 4.4 Sleep problems: the only “biohack” that matters is diagnosis
If you suspect sleep apnea (snoring, daytime sleepiness, morning headache), treat it. Untreated apnea can destroy cognitive ceiling. If insomnia persists, CBT-I is high-evidence.

- **Release** (5–15 min): capture results, set next entry point
- **Recover** (5–20 min): walk, stretch, light snack, no phone
