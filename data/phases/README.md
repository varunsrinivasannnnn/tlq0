# Phases Directory

This folder contains GPT Pro responses for each phase of tlq0 development.

## Naming Convention

- `phase_00_roadmap.md` - Initial project roadmap
- `phase_01_harness.md` - Phase 1: Experiment Harness
- `phase_02_lean.md` - Phase 2: Lean Integration (future)
- etc.

## Structure of Each File

```
# Phase N: [Name]

**Source**: [GPT 5.2 Pro / Deep Research / Gemini]
**Date**: YYYY-MM-DD
**Type**: [Roadmap / Implementation guide / Architecture decision]

---

[Content]
```

## Sub-responses

If a phase has follow-up responses, append them to the same file under:

```
---

## Follow-up: [Topic]

**Date**: YYYY-MM-DD

[Content]
```

Or create `phase_01_harness_followup_01.md` if it's substantial.
